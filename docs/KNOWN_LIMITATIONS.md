# Known limitations and honest boundaries

1. **Approved framework deviation:** React/Vite + server API rather than Next.js, explicitly approved by the user.
2. **Live providers:** OpenAI genuinely verified. Anthropic adapter implemented but not called because no credential is configured.
3. **Paid budget:** Six live attempts maximum globally and persistently; user authorized up to ₹100. Usage is billed to Replit credits. No automatic retries or dual-provider calls.
4. **AI accuracy:** LLM prose remains probabilistic. The first response misstated cumulative break-even as daily; subsequent verified responses correctly used 28 units total after stronger grounding. Deterministic financial panels remain authoritative. AI hypotheses are not proven causes.
5. **Demo understanding:** Six representative intent families and wording variations, not unrestricted natural-language understanding. Suggested questions and an explicit limitation response are provided.
6. **Language:** Four dictionaries, localized discovery/learning and representative input support are tested. Full linguistic review by native speakers has not been performed. Recorded history keeps its original language rather than silently rewriting the record.
7. **Voice:** Browser read-aloud and optional editable microphone transcript are implemented as requested. Available voices/recognition depend on the device; actual pronunciation and audio recording have not been verified. Gnani is not integrated.
8. **Imagery:** One attributed licensed South Indian breakfast photograph and ten original SVG concept illustrations. They do not depict the fictional restaurant as a real business. No paid image API was used.
9. **Persistence:** SQLite survives local API restarts. Production deployment storage/multi-instance durability is unverified. Demonstration sessions are isolated, but account-level production authentication is not provided.
10. **No external execution:** WhatsApp, QR ordering, loyalty and advertising are ideas and manual tests, not live integrations. No payments, ads, messages, customer acquisition or purchases occur.
11. **Financial model:** Contribution excludes rent, salaries, taxes and unmodeled fixed costs. Demand and making costs are hypotheses until owner-confirmed. Negative margins and insufficient results are explicitly handled.
12. **Publication:** No GitHub connection/push, repository creation, GitHub Pages activation or public application deployment has occurred. The proposed repository is unverified. A separate website is prepared only after the core validation.
13. **Recording:** Actual Chromium walkthrough videos do not contain microphone audio. No voiced demonstration is claimed.
14. **Sarvam:** Official Saaras v4/codemix and Bulbul v4 Flash documentation verified; integration deliberately pending at the feature freeze. No key, account-credit verification or speech-test authorization; no paid calls or pronunciation claims.
15. **Market intelligence:** Real IndiaRestros menu facts are periodic listings, not current offers or evidence of demand. Market-specific live-model inference is implemented but not separately paid-tested. The browser test used real retrieved facts with an explicitly deterministic Demo interpretation.
